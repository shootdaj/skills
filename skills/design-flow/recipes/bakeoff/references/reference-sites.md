# Design reference sites for the report and UI work

Component libraries you can copy from (animated, mostly React or Tailwind, easy to port to plain HTML):
- 21st.dev: https://21st.dev (community components, animated heroes, bento grids, shaders)
- Aceternity UI: https://ui.aceternity.com/components (spotlight, bento grid, beams, cards)
- Magic UI: https://magicui.design/docs/components/bento-grid (number ticker, border beam, shimmer, marquee)
- React Bits: https://reactbits.dev (micro-interactions, animated backgrounds)
- Motion Primitives: https://motion-primitives.com (built on motion.dev)
- Cult UI: https://www.cult-ui.com (shadcn style, editorial)
- shadcn blocks: https://ui.shadcn.com/blocks (dashboards, sidebars, stat cards)
- Tremor: https://tremor.so/blocks (charts and KPI dashboards)
- Origin UI: https://originui.com (400+ shadcn style pieces)
- HyperUI: https://www.hyperui.dev (Tailwind marketing and app sections)

Galleries of real shipped designs:
- Mobbin: https://mobbin.com (app and web flows, screen by screen)
- Godly: https://godly.website (curated dark, high craft sites)
- Dribbble: https://dribbble.com/search/dark-dashboard (concepts, dashboards, data viz)
- Awwwards: https://www.awwwards.com/websites/ (award level motion and layout)
- Land-book: https://land-book.com (landing pages)
- Lapa Ninja: https://www.lapa.ninja (landing pages, filter by style)
- SaaS Landing Page: https://saaslandingpage.com
- Dark Mode Design: https://www.darkmodedesign.com (dark only)
- Refero: https://refero.design (real product UI, search by component)
- Page Flows: https://pageflows.com (recorded product flows)
- Screenlane: https://screenlane.com (mobile and web patterns)
- Behance: https://www.behance.net/search/projects/dashboard%20ui

Full templates and starters:
- Framer Marketplace, dashboards: https://www.framer.com/marketplace/templates/category/dashboard/
- Vercel templates: https://vercel.com/templates
- Tailwind Plus templates: https://tailwindcss.com/plus/templates
- Once UI: https://once-ui.com (Next.js design system with strong motion)
- Preline UI: https://preline.co/examples.html
- Untitled UI: https://www.untitledui.com (Figma and React kit)

Motion and effects:
- motion.dev examples: https://motion.dev/examples
- GSAP showcase: https://gsap.com/showcase/
- Codrops: https://tympanus.net/codrops/ (advanced hover and scroll effects)
- UI Verse: https://uiverse.io (CSS buttons, loaders, cards)

3D and diagram libraries we are using in the variants:
- 3d-force-graph: https://vasturiano.github.io/3d-force-graph/example/directional-links-particles/
- three.js examples: https://threejs.org/examples/webgl_instancing_dynamic.html
- d3 gallery on Observable (sankey, chord, sunburst, radial stacked bar, arc diagram, treemap)
- elkjs for layered diagrams, rough.js for hand drawn charts

Design variants built for comparison on 2026-09-23: v1 Material baseline, D1 Obsidian Spotlight, D2 Aurora Editorial, D3 Paper and Ink, D4 Instrument HUD, D5 Liquid Chrome, D6 Swiss Broadsheet, D7 Toy Blocks, D8 Cinematic Scrollstory.
