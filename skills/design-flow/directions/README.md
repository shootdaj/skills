# Directions

One file per look. The JSON block is what the swatch board and the build read; the prose is what a builder reads. `best` and `avoid` drive which three looks the board offers for a page kind. `derived` lists values that were approximated rather than measured from the source page.

Seeded from the Skills Assessment bake-off (sk-as/design). Add a look by copying `_template.md`; a bake-off winner is added the same way.
