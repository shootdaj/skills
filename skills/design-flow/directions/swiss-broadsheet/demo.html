Swissbroadsheet

The one red E3120B

Editorial grid, hairlines, one red, print precision.

A broadsheet is a grid you can feel: columns, hairline rules and numbered figures. Type does the work colour does elsewhere. There is exactly one colour, red, and it means "look here". Everything else is ink on paper, so diagrams, schedules and tables read like a well-set engineering page. Motion stays short and mechanical: tabs turn like pages, edges draw themselves, and a pair of doors closes over the page when the edition changes.
